# 角色幻化預覽

公開網址：<https://glamour.xivtc.com/>（正式發布後生效）。使用玩家自己電腦上的《FINAL FANTASY XIV》台服遊戲資料，在瀏覽器預覽角色外貌、裝備與染劑。遊戲檔案與外貌存檔不會上傳。

開發時開啟本機站台即可；發布至 Cloudflare Pages 前務必執行 `sh deploy-prepare.sh`，並將 build output directory 設為 `_site`。大型背景資產由獨立 R2 網域提供，不在本站 repo 內。上線程序見 `docs/release-checklist.md`。
