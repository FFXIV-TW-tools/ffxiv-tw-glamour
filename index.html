使用前須知

      

        
必須在已安裝台服遊戲主程式的電腦上使用。本工具讀取你電腦上的遊戲檔案來顯示角色，沒有安裝遊戲就無法使用。

        
免責聲明與隱私

        
這是非官方的同人製作工具，與 SQUARE ENIX 或台灣營運商無關。FINAL FANTASY XIV © SQUARE ENIX。畫面僅供參考，不保證與遊戲一致，也不保證能顯示每件裝備。

        
你選取的遊戲檔案與外貌存檔不會上傳。本站只將預覽時用到的遊戲資料、角色與畫面設定保存在這個瀏覽器，供下次直接顯示；需要新的外貌或裝備時，再選遊戲資料夾。遊戲資料最多保存約 450 MB。

        
背景下載與快取

        
選好遊戲資料夾後，才會下載「室內」背景；切換到其他背景時，首次使用才下載。每個背景下載一次，之後保存在這個瀏覽器的網站資料中。要清除，可在瀏覽器設定中刪除此網站的資料；請避開有流量限制的網路。

        
正在查詢各背景的下載大小…

        
清除下方保存的遊戲資料後，下次使用需再選遊戲資料夾；已下載的背景網站資料會保留，以免重複下載。

        
        

        
顯示卡與瀏覽器

        
需要支援 WebGL2 並開啟圖形加速的桌面版瀏覽器。建議使用 Chrome 或 Edge；目前僅實測 Windows 上的 Chrome 1xx 與 NVIDIA RTX 5070 Ti，Edge 尚未實測。用處理器模擬繪圖時會非常慢。每種背景第一次出現時可能花數秒準備畫面。手機與平板目前不支援。

        
和遊戲不同的地方

        
    
          
  • 背景重現美容師畫面的 5 種場景，燈光、陰影、光暈、霧與邊緣平滑依參考畫面呈現；與實際遊戲的即時場景仍可能不同。
    • 
          
  • 角色依外貌重建；部分種族使用角色製作畫面的靜止姿勢，而非你在遊戲中的動作。不同種族的外觀尚未逐一對照遊戲畫面。
    • 
          
  • 臉部特徵尚未顯示；沒有參考畫面可用的特殊衣料或半透明裝備，可能無法更換或無法正確顯示。
    • 
          
  • 衣服與皮膚接縫可能露出細縫，脖子等連接處也可能與遊戲不同；更換裝備時，手肘、膝蓋等原本應遮住的部位可能多露出一些。
    • 
          
  • 帽子、上衣與髮型的附加部件固定在靜止姿勢；髮尾與披風不會擺動，部分上衣配件的位置尚未逐件核對。
    • 
          
  • 皺褶及交界處可能比遊戲亮，亮度會使用參考畫面的固定設定；眼睛虹膜也可能有差異。
    • 
          
  • 「挑染關」、「唇膏關」與「無臉彩」的顏色及無臉彩狀態已用台服遊戲資料核對。
    • 
        

      

      

    

  


  

    

      
請再選一次遊戲資料夾

      

        
重新開啟網頁後，瀏覽器不能自動讀取電腦上的遊戲檔案，目前畫面使用的是上次保存的資料。要換裝、調整外貌或改用還沒用過的背景，請再選一次台服遊戲資料夾。

        
如果視窗已停在你的遊戲資料夾，直接按視窗裡的「上傳」，Chrome 再問一次時也按「上傳」；檔案只在這個瀏覽器裡讀取，不會上傳。
